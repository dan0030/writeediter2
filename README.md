# 문장 엽서 v2 — 짧은 글 이미지 편집기

[dan0030.github.io/writeediter](https://dan0030.github.io/writeediter/)의 업그레이드 버전입니다. 기존 디자인과 기능은 그대로 두고 아래 기능을 더했습니다.

## 새로 추가된 기능

- **본문 정렬 4가지**: 왼쪽 · 가운데 · 오른쪽 · 양쪽 정렬
- **문단별 정렬**: 본문 안에서 선택한 문단만 다르게 정렬할 수 있습니다(「기본」을 누르면 전체 정렬을 따름).
- **색 프리셋 / 컬러코드**: 글자 색과 형광펜에서 기본 색을 고르거나, `#RRGGBB` 코드를 직접 입력하거나, 자주 쓰는 색을 프리셋으로 저장할 수 있습니다(브라우저에 보관). 형광펜 지우기도 있습니다.
- **여러 페이지**: 본문이 넘치면 자동으로 2페이지, 3페이지…로 이어지고 미리보기에서 모든 페이지를 한 번에 보며 편집합니다. `Ctrl+Enter` 또는 툴바의 「페이지 나누기」 버튼으로 원하는 곳에서 페이지를 나눌 수 있습니다.
  - 저장: 모든 페이지 PNG, ZIP 파일 하나로 묶기, 페이지별 저장, (휴대폰) 공유 시트로 사진 앱에 저장
  - 꼬리글 오른쪽 쪽 번호 자동 표시(시작 번호 지정 가능)
- **사진과 글 레이아웃의 이미지 높이 조절** + 이미지 맞춤(꽉 채우기 / 전체 보이기), 이미지 빼기
- **예시 문구**: 「輪廻 — 사라지는 것의 永遠」
- **실행 취소**: 본문을 편집하는 중에도 `Ctrl+Z`(되돌리기), `Ctrl+Shift+Z`/`Ctrl+Y`(다시 실행). 한글 입력 상태에서도 동작하고, 커서 위치가 유지됩니다.
- **모바일 최적화**: 하단 「편집 / 미리보기 / 저장」 바, 더 큰 터치 영역, iOS 입력칸 자동 확대 방지, 노치 안전 영역 대응

## 그 밖의 수정과 개선

- 손글씨 글꼴이 궁서체처럼 보이던 문제 수정: 모든 글꼴을 웹폰트(Google Fonts, Pretendard)로 불러오고, PNG로 저장할 때도 사용된 글자만 골라 폰트를 함께 넣습니다.
- 동글한 손글씨·붓글씨·나눔 명조·본고딕 글꼴 추가
- 미리보기가 편집기와 달리 연속 공백·붙여넣은 줄바꿈을 무시하던 문제 수정
- 이미지·내 폰트가 새로고침하면 사라지던 문제 수정(IndexedDB에 보관), 추가한 폰트 삭제 기능
- 타이핑·슬라이더 조작이 글자 하나, 한 칸마다 실행 취소 단계로 쌓이던 것을 묶어서 처리, 되돌리기/다시 실행 버튼 추가
- 글자 크기 변경 시 안쪽에 남은 이전 크기가 새 크기를 덮어쓰던 문제 수정
- 선택 영역 저장을 `selectionchange` 기반으로 바꿔 모바일에서도 서식이 선택한 글자에 적용되도록 수정
- 굵게/기울임/취소선 버튼에 현재 상태 표시
- 다른 곳에서 끌어다 놓은 HTML·파일이 본문에 그대로 들어가던 문제 수정(일반 텍스트로만)
- 머리글 문구가 비어 있을 때 사진 위에 빈 검은 상자가 보이던 문제 수정
- 본문 기본 글자 크기, 줄 간격 선택지 추가, 글자 크기 선택지 확장
- 휴대폰에서 1200px 지면이 화면 밖으로 넘쳐 페이지가 축소되던 문제 방지

## 개발

```bash
npm install
npm run dev     # 개발 서버
npm run build   # docs/index.html 한 파일로 빌드
```

## 배포 (GitHub Pages)

빌드 결과가 `docs/index.html` 한 파일로 저장소에 포함되어 있습니다.
저장소 **Settings → Pages → Build and deployment**에서 Source를 *Deploy from a branch*로 두고, 브랜치를 고른 뒤 폴더를 **`/docs`**로 지정하면 됩니다.
